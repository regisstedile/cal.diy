# 06. GitHub

## Resumo

Focado na integração do Git com a plataforma GitHub, o capítulo cobre desde a configuração de contas até a colaboração em projetos.

## Conteúdo

Os autores detalham como usar GitHub para gerenciar projetos de software, criando repositórios públicos e privados, colaborando por meio de pull requests e explorando as funcionalidades disponíveis.

## Destaques

> GitHub como uma popular plataforma de colaboração para projetos de código aberto.

> Uso de pull requests como meio essencial de integração de código.
