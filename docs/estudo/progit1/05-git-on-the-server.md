# 05. Git on the Server

## Resumo

Discute a configuração de repositórios Git no servidor, abrangendo diferentes protocolos e práticas recomendadas.

## Conteúdo

Este capítulo instrui o leitor sobre como configurar um servidor Git, apresentando os diferentes métodos para transferir dados (SSH, HTTP e Git protocol). Mostra como criar um repositório bare e garantir acesso aos desenvolvedores, explicando as vantagens e desvantagens de cada protocolo. A configuração de um servidor Git daemons como uma opção rápida e fácil também é abordada.

## Destaques

> Métodos para configuração de servidores Git.

> Comparação entre protocolos de transferência.
