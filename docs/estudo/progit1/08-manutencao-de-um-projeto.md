# 08. Manutenção de um Projeto

## Resumo

Apresenta a manutenção de um projeto Git, incluindo aceitação de contribuições e gerenciamento do repositório.

## Conteúdo

O capítulo explora como um mantenedor pode lidar com contribuições recebidas, integrando alterações e aplicando patches. Métodos como o uso de branches de tópico, análise de commits e as práticas recomendadas para gerenciar um repositório Git são discutidos. O capítulo também aborda a importância do controle de qualidade e das revisões de código.

## Destaques

> Estratégias de integração de código.

> Gestão de branches para manutenção.
