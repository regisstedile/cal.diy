# 02. Começando

## Resumo

Explica como instalar e configurar Git em diferentes sistemas operacionais, além de inicializar repositórios.

## Conteúdo

O autor cobre as etapas para a instalação do Git, detalhando como configurar o ambiente de trabalho pessoal, incluindo nome de usuário e endereço de e-mail, que são essenciais para os commits.

## Destaques

> Instruções práticas para instalação em Windows, macOS e Linux.

> Configuração inicial essencial para o uso do Git.
