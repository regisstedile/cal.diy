# 03. Git Basics

## Resumo

Este capítulo abrange os principais comandos do Git para manipulação de repositórios, incluindo inicialização, adição e status de arquivos.

## Conteúdo

Descreve o ciclo de vida dos arquivos no Git e as principais operações necessárias para gerenciar o código, enfatizando a importância do controle do histórico do projeto e das modificações dos arquivos.

## Destaques

> Registro de alterações e manutenção do histórico.

> Uso dos comandos git add, git commit e git status.
