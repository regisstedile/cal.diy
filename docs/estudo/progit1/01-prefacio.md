# 01. Prefácio

## Resumo

O prefácio apresenta a evolução do Git desde sua criação por Linus Torvalds e a importância do sistema no contexto do desenvolvimento de software moderno, destacando sua adoção na comunidade de código aberto e em ambientes corporativos.

## Conteúdo

O primeiro prefácio, de Scott Chacon, discute a transformação do Git de uma ferramenta obscurecida em um sistema adotado por muitas comunidades de desenvolvimento, citando o crescimento de GitHub como uma plataforma importante para colaboração. Ben Straub, no segundo prefácio, compartilha sua jornada e aprendizado com Git, enfatizando a utilidade do livro.

## Destaques

> Crescimento do Git em diversas comunidades.

> Importância de aprender a usar Git e GitHub.
