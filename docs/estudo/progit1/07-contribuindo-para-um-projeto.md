# 07. Contribuindo para um Projeto

## Resumo

Discute abordagens práticas para contribuir em projetos existentes, incluindo o uso de forks e envio de patches.

## Conteúdo

O capítulo detalha como os desenvolvedores podem interagir com projetos open-source, utilizando forks para criar cópias de projetos para trabalho individual. Também são abordados métodos para enviar patches ou pull requests, e como manter uma comunicação eficaz com os mantenedores do projeto. Adicionalmente, fornece um guia sobre boas práticas na escrita de mensagens de commit.

## Destaques

> Uso de forks para contribuições.

> Como lidar com patches e pull requests.
