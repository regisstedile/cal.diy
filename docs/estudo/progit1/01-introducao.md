# 01. Introdução

## Resumo

O capítulo introduz Git como um sistema de controle de versão, suas vantagens e a importância crescente em projetos de código aberto.

## Conteúdo

Os autores iniciam com uma visão histórica sobre controle de versão, levando à criação do Git, focando em sua eficiência, embora a curva de aprendizado possa ser desafiadora.

## Destaques

> Git é um sistema de controle de versão distribuído.

> Permite que múltiplos desenvolvedores colaborem em um projeto sem interferência mútua.
