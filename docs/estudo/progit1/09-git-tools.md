# 09. Git Tools

## Resumo

Explora ferramentas adicionais para trabalhar com Git, incluindo hooks e scripts personalizados.

## Conteúdo

Este capítulo discute ferramentas e capacidades adicionais no uso do Git. Aborda como usar hooks para automatizar processos no fluxo de trabalho e como personalizar o comportamento do Git com scripts. O livro também menciona várias opções avançadas que podem ser aplicadas para melhorar a eficiência e integração com outras ferramentas de desenvolvimento.

## Destaques

> Uso de hooks para automação.

> Scripts personalizados para Git.
