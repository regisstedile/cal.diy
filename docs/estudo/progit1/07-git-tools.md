# 07. Git Tools

## Resumo

Este capítulo se aprofunda nas ferramentas avançadas e funcionalidades do Git, como alias e hooks.

## Conteúdo

Aborda utilização de recursos como alias para facilitar comandos do Git, além de hooks que permitem customizar eventos que ocorrem durante o ciclo de vida do repositório. O uso de ferramentas como git rerere para resolver conflitos repetitivos é discutido.

## Destaques

> Ferramentas para otimização do fluxo de trabalho.

> Uso de alias para reduzir a complexidade em comandos Git.
