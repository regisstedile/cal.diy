# 02. Introdução

## Resumo

Apresenta conceitos fundamentais sobre controle de versão e introduz o Git, explicando suas características únicas e a lógica por trás de suas operações.

## Conteúdo

O capítulo examina os sistemas de controle de versão, explicando a evolução dos modelos de controle local, centralizado e distribuído. O Git é apresentado como uma solução moderna que permite operações locais rápidas e seguras, armazenando informações em snapshots ao invés de apenas alterações entre arquivos. Este enfoque torna o Git eficiente e capaz de lidar com grandes projetos.

## Destaques

> Diferenças entre VCS tradicionais e Git.

> A importância de entender como o Git armazena informações.
