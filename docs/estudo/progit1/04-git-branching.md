# 04. Git Branching

## Resumo

Explora o sistema de branches do Git, sua criação, exclusão e estratégias de fusão, detalhando os fluxos de trabalho recomendados.

## Conteúdo

O capítulo apresenta o conceito de branches no Git, explicando como criar, alternar e gerenciar branches de forma eficaz. Vários padrões de branching são discutidos, incluindo estratégias de fusão e uso de branches de longa duração versus branches de tópico. O rebase é introduzido como uma alternativa ao merge, destacando quando é apropriado usar cada um deles.

## Destaques

> Criação de branches de tópico.

> Estratégias de fusão e rebase.
