# 03. Hooks do React

## Resumo

Aqui, diferentes hooks do React são apresentados, como useState e useEffect, com exemplos práticos de seu uso e aplicação em projetos.

## Conteúdo

Exploramos hooks comuns como o useState para gerenciar o estado interno dos componentes e o useEffect para lidar com efeitos colaterais como fetch de dados. O capítulo enfatiza a importância do gerenciamento efetivo de estado e efeitos em aplicações React.

## Destaques

> Uso de useState e useEffect

> Gerenciamento de estado em componentes

> Importância do gerenciamento de efeitos
