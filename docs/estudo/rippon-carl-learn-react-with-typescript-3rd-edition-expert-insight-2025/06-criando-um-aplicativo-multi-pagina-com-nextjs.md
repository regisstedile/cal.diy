# 06. Criando um Aplicativo Multi-página com Next.js

## Resumo

Aqui, a estrutura e os conceitos para criar aplicativos multi-página com o Next.js são discutidos, mostrando como construir rotas e layouts compartilhados.

## Conteúdo

Neste capítulo, exploramos a criação de aplicações multi-página usando Next.js. O autor guia o leitor através da configuração de rotas, navegação e como implementar layouts que sejam consistentes em diferentes páginas do aplicativo.

## Destaques

> Estruturação de rotas em Next.js

> Importância de layouts compartilhados

> Implementação de navegação entre páginas
