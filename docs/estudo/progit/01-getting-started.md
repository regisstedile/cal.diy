# 01. Getting Started

## Resumo

Introduces version control systems, sets up Git on different operating systems, and highlights essential commands.

## Conteúdo

This chapter covers the basics of version control systems (VCS) and how Git fits into the landscape. It outlines the steps for installing Git on various platforms like macOS, Linux, and Windows, and gives a primer on Git commands such as init, add, commit, and status. The content reinforces the advantages of using Git over other VCS options.

## Destaques

> Understanding version control is critical for software development.

> Git's local capabilities enhance performance and offline work.
