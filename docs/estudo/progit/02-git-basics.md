# 02. Git Basics

## Resumo

Teaches essential Git commands and concepts, including tracking files, commit history, and undoing changes.

## Conteúdo

This chapter delves deeper into the core functionalities of Git. It explains the difference between modified, staged, and committed states of files and how to navigate through them effectively using commands like git status, git add, and git commit. By the end of this chapter, the reader should be comfortable managing their local repository.

## Destaques

> git add stages files for commits.

> Understanding the difference between tracked and untracked files is crucial for effective management.

## Conceitos

- Staging
- Committing
- Undoing Changes
