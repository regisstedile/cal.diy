# 03. Git Branching

## Resumo

Explains branching strategies and how Git makes branching easy and effective.

## Conteúdo

The chapter discusses the concept of branches and how they enable isolated development in Git. It covers the steps to create, switch, and delete branches, as well as the importance of merging and its implications on the workflow. The reader learns to utilize branches to facilitate collaboration and manage project history efficiently.

## Destaques

> Branching is considered a 'killer feature' of Git.

> Merging branches requires understanding how to handle conflicts effectively.

- Branching Strategy
- Merging
- Conflict Resolution
