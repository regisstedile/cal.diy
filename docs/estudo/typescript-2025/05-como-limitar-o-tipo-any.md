# 05. Como limitar o tipo any

## Resumo

Discute as implicações do uso do tipo any e como limitar seu uso para manter a segurança do código.

## Conteúdo

A utilização de any é desencorajada, sendo sugerido o uso de tipos mais específicos ou o uso de unknown. Isto ajuda a manter os benefícios da tipagem estática.

## Destaques

> O uso excessivo de any pode levar a falhas de segurança.

> Substituir any por tipos mais específicos mantém a segurança do código.
