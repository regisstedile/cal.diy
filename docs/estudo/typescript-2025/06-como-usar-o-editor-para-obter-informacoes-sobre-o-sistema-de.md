# 06. Como usar o editor para obter informações sobre o sistema de tipos

## Resumo

Explora as funcionalidades do editor (como VS Code) para facilitar a compreensão e utilização dos tipos em TypeScript.

## Conteúdo

As funcionalidades do editor, como sugestões de tipos e navegação por definição são discutidas, ajudando no aprendizado e uso do TypeScript.

## Destaques

> O editor fornece feedback em tempo real sobre tipos.

> Facilita a navegação pelo código e melhorias na eficiência.
