# 03. Geração de Código Não Dependente de Tipos

## Resumo

Explora como o TypeScript permite a geração de código independente de tipos e como isso afeta a implementação pragmática.

## Conteúdo

Neste capítulo, o autor discute como os tipos em TypeScript influenciam a geração de código e destaca a importância de entender que os tipos são removidos no processo de compilação. Isso permite que o desenvolvedor escreva código seguro, mas que ainda se comporte como JavaScript no final.

## Destaques

> Os tipos são vitais durante o desenvolvimento, mas não existem em tempo de execução.
