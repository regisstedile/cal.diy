# 02. Configurando o Ambiente

## Resumo

Orientações sobre como preparar o ambiente de desenvolvimento para TypeScript.

## Conteúdo

No segundo capítulo, o autor fornece um guia passo a passo para configurar o ambiente de desenvolvimento, incluindo a instalação do TypeScript e das ferramentas necessárias, como editores de código e pacotes adicionais. Há ênfase na configuração do compilador TypeScript e como integrá-lo ao fluxo de trabalho existente para projetos JavaScript.

## Destaques

> Instalação do TypeScript via npm.

> Configuração do tsconfig.json.
