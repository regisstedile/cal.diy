# 03. Trabalhando com Interfaces

## Resumo

O terceiro capítulo é dedicado às interfaces em TypeScript, mostrando como podem ser utilizadas para definir a forma de objetos.

## Conteúdo

Interfaces são uma parte essencial do TypeScript. Este capítulo explora como criar, implementar e extender interfaces. O autor fornece exemplos de como as interfaces podem ser usadas para garantir que objetos tenham a estrutura correta, facilitando a colaboração em projetos maiores e a manutenção do código.

## Destaques

> Criação de interfaces e implementação de contratos.

> Extensão de interfaces para reutilização de código.

> Diferença entre interfaces e tipos.
