# 04. Programação Orientada a Objetos com Classes

## Resumo

Este capítulo aborda a programação orientada a objetos em TypeScript, focando na utilização de classes.

## Conteúdo

O autor discute como o TypeScript suporta a programação orientada a objetos através de classes. São abordados conceitos como herança, encapsulamento e polimorfismo, mostrando como utilizá-los efetivamente no desenvolvimento de aplicações. Exemplos práticos ilustram como as classes podem ser usadas para organizar o código de forma eficiente.

## Destaques

> Herança e polimorfismo em TypeScript.

> Encapsulamento de dados usando classes.

> Estruturas de objetos complexos através de classes.
