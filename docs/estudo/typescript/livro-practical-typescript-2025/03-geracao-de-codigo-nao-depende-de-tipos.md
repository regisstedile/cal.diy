# 03. Geração de código não depende de tipos

## Resumo

Aborda como a geração de código em TypeScript é feita sem a necessidade de tipos, focando na construção de código que é seguro em tempo de desenvolvimento.

## Conteúdo

Discute a separação entre tipos de desenvolvimento e execução. Gerações de código são descritas como um meio de aumentar a produtividade sem sacrificar a segurança.

## Destaques

> Tipos são removidos na compilação, mas ajudam no desenvolvimento.

> A geração de código correta melhora a eficiência.
