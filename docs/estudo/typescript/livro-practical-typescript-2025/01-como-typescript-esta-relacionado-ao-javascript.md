# 01. Como TypeScript está relacionado ao JavaScript

## Resumo

Nesta seção, o autor destaca as principais diferenças entre TypeScript e JavaScript e como TypeScript melhora a experiência de desenvolvimento.

## Conteúdo

TypeScript é uma superconjunto de JavaScript que adiciona tipagem estática, permitindo que os desenvolvedores escrevam códigos mais seguros. O autor explica como as verificações de tipo em tempo de compilação ajudam a evitar erros que seriam descobertos apenas em tempo de execução ao usar JavaScript puro.

## Destaques

> TypeScript é uma extensão do JavaScript.

> Verificações de tipos melhoram a qualidade do código.
