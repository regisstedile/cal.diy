# 02. Como escolher as opções necessárias no TypeScript

## Resumo

Explica como configurar o arquivo tsconfig.json para adaptar o comportamento do compilador TypeScript às necessidades do desenvolvedor.

## Conteúdo

As opções como strict, target e module são discutidas, enfatizando a importância de escolher configurações que reflitam as melhores práticas de desenvolvimento.

## Destaques

> Opção 'strict' aumenta a segurança do código.

> Configurações erradas podem levar a erros não detectados.
