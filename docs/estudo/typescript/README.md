# Estudo TypeScript aplicado ao cal-diy

Este diretório reúne notas próprias de estudo, não cópia integral dos livros/PDFs.

## Materiais

- `curso-frontendmasters-typescript-fundamentals/` — análise da transcrição do curso Frontend Masters TypeScript 5+ Fundamentals.
- `livro-total-typescript-essentials/` — notas do livro _Total TypeScript: The Essentials_.
- `livro-practical-typescript-2025/` — notas/checklist do livro _Практический TypeScript_.
- `livro-react-typescript-rippon/` — notas do livro _Learn React with TypeScript, 3rd Edition_, focadas em `apps/web`, Next.js, hooks, forms, data fetching e testes.

## Regra

Cada sessão de estudo deve produzir:

1. Conceito TypeScript.
2. Exemplo mínimo.
3. Exemplo real no `cal-diy`.
4. Risco de manutenção evitado.
