# 03. TYPESCRIPT IN THE DEVELOPMENT PIPELINE

## Resumo

Nesse capítulo, o autor explica como o TypeScript se integra às ferramentas de desenvolvimento modernas e sua aplicação no pipeline de desenvolvimento, incluindo o tratamento de erros e a transpiração do código.

## Conteúdo

A discussão começa sobre a importância do TypeScript no desenvolvimento moderno, especialmente com o uso de frameworks populares. O foco recai sobre o processo de transpiração, que converte arquivos TypeScript em JavaScript. O capítulo cobre também como usar o TypeScript com ferramentas como Webpack e Babel, além de abordar considerações de versionamento de código.

## Destaques

> Abordagem sobre transpiração de TypeScript para JavaScript.

> Integração com frameworks modernos.

> Definição de TypeScript como ferramenta vital no pipeline de desenvolvimento.
