# 01. KICKSTART YOUR TYPESCRIPT SETUP

## Resumo

Este capítulo apresenta aos leitores os aspectos fundamentais do TypeScript, incluindo o que o diferencia do JavaScript tradicional. O autor discute a configuração do ambiente de desenvolvimento e as ferramentas necessárias para trabalhar efetivamente com TypeScript.

## Conteúdo

A introdução cobre as diferenças entre TypeScript e JavaScript, enfatizando a importância dos tipos e da tipagem estática. O leitor é guiado por um processo passo a passo de instalação e configuração. O estabelecimento de um ambiente de desenvolvimento é desenvolvido com clareza, instruindo os usuários sobre como instalar Node.js e o gerenciador de pacotes pnpm. Este capítulo também aborda a instalação do TypeScript e a configuração do projeto.

## Destaques

> Importância dos tipos no desenvolvimento.

> Diferenciação entre TypeScript e JavaScript.

> Configuração do ambiente TypeScript.
