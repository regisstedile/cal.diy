# 09. TYPESCRIPT-ONLY FEATURES

## Resumo

Este capítulo explora as funcionalidades exclusivas do TypeScript e sua evolução em resposta ao JavaScript moderno.

## Conteúdo

Pocock discute características como enums e namespaces, ressaltando a importância de evoluir com as práticas modernas de programação. Ele explica como tipos gerados do TypeScript compõem o código JavaScript, e discute os trade-offs associados a enums e namespaces em um ambiente JavaScript contemporâneo. O autor também aborda a evolução do TypeScript como um sistema de tipos, enfatizando que as melhores práticas devem agora girar ao redor da sintaxe JS.

## Destaques

> Funções e características exclusivas do TypeScript.

> Comparação entre enums e objetos simples.

> A evolução da filosofia do TypeScript vis-à-vis JavaScript.
