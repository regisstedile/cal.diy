# 03. Using React Hooks

## Resumo

Aborda os hooks do React, principalmente useEffect e useState, e como eles são utilizados para gerenciar o estado e os efeitos colaterais na aplicação.

## Conteúdo

Demonstrando exemplos práticos de como implementar hooks em componentes, permitindo a criação de interfaces reativas e interativas.

## Destaques

> Gerenciamento de estado com useState

> Efeitos colaterais com useEffect
