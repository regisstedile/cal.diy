# 09. Trabalhando com Formulários

## Resumo

Neste capítulo, o autor ensina a criar e gerenciar formulários, com foco em validações e submeter dados de forma simples.

## Conteúdo

O capítulo captura a essência dos formulários na criação de interfaces, implementando formas de capturar informações do usuário enquanto valida e responde a erros, criando uma experiência de usuário agradável.

## Destaques

> Criação de formulários com React

> Validação e manuseio de estados de erro

> Implementação de atualizações otimistas em formulários
