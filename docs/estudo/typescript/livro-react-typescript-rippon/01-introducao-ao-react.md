# 01. Introdução ao React

## Resumo

O primeiro capítulo apresenta as bases do React, incluindo a criação de projetos e a estrutura de um aplicativo React.

## Conteúdo

Neste capítulo, discutimos o que é o React e como ele permite a construção de interfaces de usuário por meio de componentes reutilizáveis. Os autores detalham a instalação do ambiente de desenvolvimento e a criação do projeto inicial utilizando Vite.
