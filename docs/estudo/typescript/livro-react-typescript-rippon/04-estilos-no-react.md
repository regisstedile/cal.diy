# 04. Estilos no React

## Resumo

O autor discute várias abordagens para estilizar componentes React, incluindo CSS puro, CSS Modules e Tailwind.

## Conteúdo

Neste capítulo, abordamos métodos de estilização de componentes React, comparando a simplicidade do CSS puro com a modularidade do CSS Modules e as vantagens do Tailwind CSS. Exemplos práticos demonstram a implementação de cada abordagem em um componente de alerta.
