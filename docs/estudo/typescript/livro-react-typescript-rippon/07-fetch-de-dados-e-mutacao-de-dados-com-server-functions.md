# 07. Fetch de Dados e Mutação de Dados com Server Functions

## Resumo

Este capítulo ensina como realizar fetch de dados com Server Components e apresenta o conceito de mutações de dados.

## Conteúdo

O autor aborda como buscar dados utilizando Server Functions e omitir as desvantagens do Client-side data fetching, melhorando a experiência do usuário com carregamentos e tratativas de erro eficientes.

## Destaques

> Fetch de dados de servidores

> Uso de React Suspense para carregamento

> Mutações seguras de dados com Server Functions
