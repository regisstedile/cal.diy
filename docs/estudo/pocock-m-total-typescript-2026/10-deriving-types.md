# 10. DERIVING TYPES

## Resumo

O autor introduz conceitos de derivação de tipos, permitindo reduzir a repetição e criar uma única fonte da verdade para os tipos na aplicação.

## Conteúdo

Neste capítulo, o leitor aprende a criar novos tipos a partir de tipos existentes, utilizando utilitários como keyof, typeof e indexed access types. O autor enfatiza a importância de manter a DRY (Don't Repeat Yourself) enquanto explica como transformar tipos repassando valores para manter a integridade semântico-micro do código.

## Destaques

> Derivação de tipos com keyof e typeof.

> A importância de manter tipos em uma única fonte.

> Aprendizado sobre tipos com transformações.
